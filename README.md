# Mi IPTV Android
Proyecto Android nativo Kotlin con Xtream Codes API, categorías de TV en vivo y reproductor Media3.

## Datos iniciales de conexión
- Host: tv.m3uts.xyz
- Usuario: m
- Contraseña: m

Estos datos están precargados en la interfaz; podés cambiarlos en la app.

## Compilar con GitHub Actions
1. Subí el contenido de este proyecto a un repositorio GitHub.
2. Abrí la pestaña **Actions**.
3. Ejecutá **Build Android APK** (o subí cambios a main/master).
4. Abrí la ejecución completada y descargá el artefacto `Mi-IPTV-debug`.

## Nota
La sección Eventos es una pantalla inicial preparada para la siguiente etapa de desarrollo (eventos manuales con fecha, imagen y stream). La compatibilidad y reproducción dependen de que el proveedor permita el acceso y entregue streams válidos.
